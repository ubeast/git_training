# Videos

Short videos referenced during the Git course.

Video files are **not** tracked in this repo — they're excluded via the root
`.gitignore` (git handles large binaries poorly). Only `README.md` and
`links.md` are committed.

To follow along locally, use [`links.md`](links.md) to stream each video or drop
your own copy of the file into this folder. `links.md` also notes which module
each video pairs with.
