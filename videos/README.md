# Videos

Videos referenced or watched during the training class.

Video files are **not** tracked in this repo — they're excluded via
`.gitignore` (git repos handle large binaries poorly). Place your own copy
of each video in this folder locally; only `README.md` and `links.md` are
committed to GitHub.

See [`links.md`](links.md) for a link to each video so participants can
download or stream their own copy instead of a file being committed here.
